# Steam 模块

显示登录用户最近两周玩过的游戏（最多 `layout.yaml` 里配置的 `count` 款），正在玩的游戏会显示在卡片标题旁。悬停某一行能看到总时长和最后游玩日期。

## 申请 API Key

去 <https://steamcommunity.com/dev/apikey> 申请一个 Steam Web API Key（需要登录 Steam 账号；域名一栏可以随便填一个占位值，比如 `localhost`）。拿到的是一个 32 位十六进制字符串。

## 配置

设置服务端环境变量 `STEAM_API_KEY`。**这个值只应该出现在服务器的环境变量里，绝不要提交进代码库**（`.env` 已经在 `.gitignore` 里）：

```
STEAM_API_KEY=你申请到的key
```

没有配置这个变量时，Steam 卡片会显示"服务器还没有配置 Steam API Key"，这是正常状态，不影响网站其他部分。

## 绑定账号

每个登录用户（见 [AUTH.md](AUTH.md)）在 Steam 卡片底部的表单里绑定自己的账号，填以下任一种：

- SteamID64（17 位数字，`7656119` 开头）
- 个人资料链接：`steamcommunity.com/profiles/<SteamID64>`
- 自定义链接：`steamcommunity.com/id/<自定义名>`（这种需要服务器配置了 API Key 才能解析成 SteamID64）

绑定还需要 Steam 隐私设置里「游戏详情」是公开的，否则会显示"拿不到游玩记录"的提示。路径：Steam 客户端或网页版 → 编辑个人资料 → 隐私设置 → 游戏详情。

## 缓存与容错

- 游戏列表缓存 15 分钟，过期后先返回旧数据、后台刷新；刷新失败会继续显示旧数据并标注"暂时连不上"
- 昵称、在线状态缓存 2 分钟
- 请求 Steam API 超时会自动重试一次；HTTP 错误（如 401/429）不重试
- 封面图从 Steam 官方 CDN 直接在浏览器加载，不经过你的服务器

## 网络受限环境（可选）

如果你的服务器访问 `api.steampowered.com`（或 `steamcommunity.com`）不稳定，Node 支持通过环境变量走出站代理：

```
NODE_USE_ENV_PROXY=1
HTTPS_PROXY=http://你的代理地址
```

**注意**：这个设置是进程级的，会同时影响日历模块访问 ICS 订阅地址的请求。如果你配置了这个代理，务必在代理侧加上私有网段（如 `10.0.0.0/8`、`192.168.0.0/16`、`127.0.0.0/8`）的拒绝规则，防止代理被滥用来探测你的内网。这部分本项目只提供说明，没有内置代码实现。
